# جزوهٔ فارسی «مرتب‌سازی در زمان خطی»

جزوهٔ خودآموز درس الگوریتم و ساختمان داده، بر پایهٔ فایل ۲۵ اسلایدی **Sorting.pdf** با عنوان *Sorting in Linear Time*. ترتیب اسلایدها حفظ شده است: مرور مرتب‌سازی‌های مقایسه‌ای، اثبات کران پایین، Counting Sort، پایداری، Radix Sort و جمع‌بندی. مثال‌های تصویری اسلایدها به جدول‌ها و یک درخت تصمیمِ بازطراحی‌شده تبدیل شده‌اند. پرسش‌های خود اسلایدها پاسخ داده شده‌اند؛ تمرین‌های افزوده برچسب «تکمیلی» دارند. ناسازگاری‌های اندیس‌گذاری اسلایدها به‌صراحت در متن مشخص شده‌اند.

## خروجی‌ها

- [نسخهٔ وب](index.html) — فهرست پیمایشی و طراحی واکنش‌گرا؛ نشانی GitHub Pages پس از انتشار: `https://artamote.github.io/sorting-linear-time-fa/`
- [PDF مناسب چاپ](guide.pdf) — A4، ۱۲ صفحه، فونت‌های جاسازی‌شده
- [نگاشت اسلایدها به جزوه](COVERAGE.md)

## ساخت دوباره

نیازمند Node.js و Chromium/Chrome است.

```bash
npm ci
npm run build
npx playwright install chromium
npm run build:pdf
```

اگر Chrome از قبل نصب است، می‌توان مسیر آن را در متغیر `CHROME_PATH` برای دستور آخر مشخص کرد. `build.mjs` فصل‌های Markdown را می‌خواند، فرمول‌های نوشته‌شده با LaTeX را با KaTeX به HTML تبدیل می‌کند و نسخهٔ وب را می‌سازد. سپس در حالت PDF از Chromium برای چاپ استفاده می‌کند. متن فارسی با Vazirmatn و قطعه‌های کد با JetBrains Mono نمایش داده می‌شوند. فایل‌های فونت و KaTeX موردنیاز نسخهٔ وب در `assets/` همراه ریپو قرار دارند؛ سایت پس از بارگیری به CDN وابسته نیست.

## فایل‌های پروژه

- `chapters/`: متن اصلی و قابل ویرایش، به ترتیب آموزشی
- `assets/style.css`: طراحی وب و چاپ
- `assets/insertion-decision-tree.svg`: بازطراحی آموزشی مثال درخت تصمیم اسلاید ۸
- `build.mjs`: ساخت HTML و PDF
- `.github/workflows/pages.yml`: ساخت خودکار و انتشار خروجی‌ها در GitHub Pages پس از فعال‌سازی Pages با منبع GitHub Actions
- `index.html` و `guide.pdf`: خروجی‌های تولیدشده

## منبع و محدوده

**ورودی استفاده‌شده:** `Sorting.pdf`، ارائهٔ *Sorting in Linear Time*، ۲۵ اسلاید، دریافت‌شده از کاربر. فایل اصلیِ کلاسی در این ریپو منتشر نشده است؛ فقط نگاشت اسلایدها و محتوای بازنویسی‌شده قرار دارد. این جزوه یک بازنویسی آموزشی است و تأیید رسمی درس یا مدرس را ندارد. موارد نیازمند بررسی انسانی شامل تطبیق تفسیر شکل‌های اسلاید ۷ و ۸ با توضیح مدرس و تصمیم دربارهٔ انتشار عمومی مطالب درسی است.
